The `db.sqlite` module can open/create SQLite databases

<SchemaInfo type="module" id="db.sqlite"></SchemaInfo>

This module implements the `DatabaseModule` interface.


### Example

Opens an in-memory SQLite database

```yaml
- id: myDatabase
  type: db.sqlite
  params:
    dsn: ":memory:"
```
